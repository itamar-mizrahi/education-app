# **App Name**: EduVibe

## Core Features:

- fast forward option: x2 x1.5
- summary: summary
- Video Playback: Interactive video player with controls for playback, pausing, and seeking.
- Integrated Quizzes: Short quizzes that appear after video segments to reinforce learning.
- Timestamped Note-Taking: Users can take notes that are automatically timestamped to the current video time.
- Flashcard Creation: Create flashcards directly from video content, linked to specific timestamps.
- Progress Dashboard: Visual dashboard showing learning progress and achievements.
- Video Review Navigation: Easy navigation to review specific parts of the video.

## Style Guidelines:

- Primary color: Vibrant blue (#5072A7) to create a calming and engaging atmosphere, reflective of focus and trust.
- Background color: Light blue (#D1D9E6), subtly desaturated, complementing the primary color.
- Accent color: Yellow (#E7C664), an analogous color, used for highlighting interactive elements to draw user's attention.
- Body and headline font: 'PT Sans', a humanist sans-serif font, will ensure clarity and readability throughout the platform.
- Consistent and clear icons that match the educational context.
- Clean and intuitive layout to facilitate easy navigation and a distraction-free learning environment.
- Subtle animations to provide feedback on interactions and enhance user engagement without being distracting.
